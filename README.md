# VibeGit change summary

A guide to the change-summary Skill maintained in [VibeGit](https://github.com/lllleolin-max/VibeGit). The Skill records a short, beginner-friendly explanation after coding work in a project with VibeGit protection enabled, so the next checkpoint can show what changed.

这是 VibeGit 改动摘要 Skill 的导航仓库：帮助已开启版本保护的项目记录易读的改动说明。**本仓库目前不包含独立 Skill 实现或安装包。**

## Get the maintained Skill

1. Read the [VibeGit setup instructions](https://github.com/lllleolin-max/VibeGit#开始使用).
2. Inspect the maintained [Skill source and instructions](https://github.com/lllleolin-max/VibeGit/tree/main/skills/vibegit-change-summary).
3. Follow that version's installation instructions for your agent, then enable protection and create a checkpoint in VibeGit.

Installing a Skill alone does not back up files or create a saved version. Its instructions apply when the project's local `.git/vibegit/protected.json` marker enables it. Keep the Skill and the VibeGit version you use compatible.

## Status and feedback

The implementation, integration instructions and development history are maintained in the main VibeGit repository. Report integration problems through [VibeGit Issues](https://github.com/lllleolin-max/VibeGit/issues), including the app version, agent, expected result and actual result; omit private project contents and credentials.
